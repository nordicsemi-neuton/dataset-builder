# Dataset Storage: dataset management

## dataset-management

Datasets uploaded to the platform for training or validation are stored in the dataset list. You can perform the following actions on any dataset:

* **Delete dataset** — Permanently removes the dataset.
* **View dataset** — Opens the dataset for review.
* **Download dataset** — Downloads the dataset to your local machine.

Use the icons next to each dataset name to perform these actions.
