# Solution creation

Creating a new solution is the first step in the model creation process within Nordic Edge AI Lab. The solution is your workspace where you specify all training parameters, manage results, and perform analysis.

All your solutions are available for review and management in the **My Solutions** workspace. Here you can see, edit, and organize your created solutions.

## Creating a new solution

**Step 1:** To create a new solution, click **Add New Solution**. A pop-up window titled **New Solution** will appear.

**Step 2:** Enter your solution name using Latin letters.

**Step 3:** Select the **Task Type**, which depends on the selected technology:

- **Neuton:**
  - Classification
  - Regression
  - Anomaly Detection
- **Axon NPU:**
  - Classification
  - Regression
  - Wake Word Detection

**Step 4:** Once completed, click **Next** to proceed to dataset import and configuration.

If you wish to check if your data meets the requirements for training, see the dataset requirements section.
