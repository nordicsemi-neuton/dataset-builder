- [ADR-0004 — resample re-quantizes an integral sensor column (narrows ADR-0002)](decisions/adr-0004-resample-integer-preservation.md) — on the resample path only, a sensor column whose every source value was a whole number is rounded back to whole numbers (stays float64, never cast; `resample_integer_preserved` INFO), so resampling stops fabricating decimal precision and `recommend_dtype` recovers INT8/INT16; the writer is unmodified and the non-resampled path is byte-identical. B4, dated after 0005–0007 (number reserved). _Updated: 2026-07-27_
- [ADR-0005 — .zip intake + a raised head bound (amends ADR-0002)](decisions/adr-0005-zip-intake-and-head-bound.md) — resolve a .zip to one member via a single helper shared by both readers (extension not signature; read inside the guard so corrupt/encrypted stop crashing; OSError excluded so missing stays exit 4); raise the field-count head bound 64 KB → 1 MiB line-aligned; non-overridable prep write guard. _Updated: 2026-07-25_
- [ADR-0006 — Signal-Processing mode is a profile-declared check scope (narrows ADR-0002)](decisions/adr-0006-signal-processing-mode.md) — tri-state `signal_processing` field; on `validate`, SP-off skips the nine window checks + discloses via ADVISORY `sp_off_unverified` (never blocking — the incentive gradient); back-compat by the `sp_on=None` legacy contract. Extended to prep/quality by ADR-0007. _Updated: 2026-07-25_
- [ADR-0007 — SP mode governs the prep/quality write-analysis surfaces (extends ADR-0006, narrows ADR-0002)](decisions/adr-0007-sp-off-prep-quality-surface.md) — prep skips centering + refuses `--resample` under SP-off, writes the honest tabular file (gradient preserved); `_resolve_mode` returns `(sp_on, window)`; `sp_off_window_ignored`/`sp_off_resample_refused`; `--window 0`→exit 4; `center_per_class` guards a bad window. _Updated: 2026-07-25_
